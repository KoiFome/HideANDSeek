# HIDE & Seek

Yes, is my first time making a videogame (using also the ECS style) so
I had to learn a lot of stuff. I'll try to use this as a First approach
before making real projects in Android. 

The game is pretty simple, you just have to move around with your phone
and try to find the hidden character (she's Mokou btw), you have only
one minute to check for her before she run away and leave you alone
in the Forest. 

I hope anyone who plays it, have a nice experience and, if you want to, 
give me a hand to learn more about Kotlin and ECS because I'm not lying, 
this was a really confusing model and everything was learned by the scratch
